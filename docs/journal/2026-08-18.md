## Problèmes → solutions

- **Docker Desktop éteint** (`npipe … dockerDesktopLinuxEngine` introuvable) →
  démarrage de `Docker Desktop.exe`, le daemon répond ensuite.
- **`URL::forceScheme('https')` dans `AppServiceProvider`** dès que `APP_ENV !== local` :
  casserait la stack locale servie en HTTP → `APP_ENV=local` dans `.env.docker`,
  avec un commentaire dans le fichier pour que ça ne reparte pas en production.
- **Container orphelin** `ifosup-display-app-1` publié sur 8090, vestige d'un compose
  antérieur supprimé du repo → recréé proprement par le nouveau compose.
- **`storage:link` sous `set -e`** : échoue si le lien existe déjà et tuait le
  container au second démarrage → `--force || true`.
- **Route `/debug-excel` publique** avec un `dd()` sur le planning importé → ticket
  IFO-003, à traiter avant la mise en ligne.

### Problèmes → solutions

- **Migrations cassées sur MySQL** : `create_assignments` déclarait une clé étrangère
  vers `recurring_assignments`, table créée dix jours plus tard dans l'ordre des
  migrations. Invisible en SQLite (contraintes non appliquées), bloquant sur MySQL et
  PostgreSQL → migration renommée `2026_03_16_140900_...`, contenu inchangé (IFO-006).
- **23 tests en échec sur `Vite manifest not found`** : la suite PHP exigeait un
  `npm run build` préalable → `$this->withoutVite()` dans `Tests\TestCase`.
- **19 échecs résiduels** : tests du starter kit visant des routes inexistantes
  (inscription, réinitialisation, vérification d'email — désactivées dans
  `config/fortify.php`) et une route `dashboard` qui n'existe pas → quatre fichiers
  supprimés, `DashboardTest` et `AuthenticationTest` réorientés vers `/scheduler`.
- **ESLint non déterministe** : son résultat dépend de la présence des fichiers
  générés par Wayfinder — `resources/js/{actions,routes}` est gitignoré, et
  `import/order` classe ces imports différemment selon qu'ils sont résolvables ou non.
  37 erreurs d'écart entre les deux états. → génération Wayfinder ajoutée à `lint.yml`
  avant les vérifications front, code figé dans l'état « Wayfinder présent ».
  C'est le piège le plus coûteux de la journée : sans ça, la CI et les postes de
  développement auraient divergé en permanence.
- **Analyse d'agent à vérifier** : `bulkPreview` était présenté comme un bug (conflits
  renvoyés pour tous les locaux). Lecture du front : `Scheduler.vue:1104` refiltre déjà
  par `room_id`. Ce n'était donc pas un bug fonctionnel mais du sur-transfert — filtre
  ajouté quand même, mais requalifié dans le plan. Leçon : vérifier l'impact réel côté
  consommateur avant de qualifier un bug.
- **`Storage::url()` sur le disque `local`** semblait cassé pour les médias de slides.
  Vérification dans le container : il retourne `/storage/...`, une URL relative qui
  résout via le lien symbolique. Seul `delete()` était réellement fautif.
- **Suppressions de fichiers bloquées** par la sandbox, ainsi que la forme
  `docker compose run --entrypoint sh -c '...'`. Contournement : passer la commande
  directement après le nom du service (`... run --rm --no-deps app php artisan test`).
