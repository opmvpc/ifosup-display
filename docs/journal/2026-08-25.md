## Leçons / pièges d'environnement

- Le service `vite` du docker-compose dev ne reçoit pas les événements de
  fichiers du montage Windows : après création de nouveaux fichiers front,
  `docker compose -f docker-compose.dev.yml restart vite` (premier chargement
  lent, ~50 s).
- Le container est en UTC : pour des données « du jour » vues par l'écran
  (Europe/Brussels), toujours passer le fuseau explicitement
  (`now('Europe/Brussels')`).
- Les `node_modules` du repo sont installés depuis le container Linux
  (symlinks pnpm cassés côté Windows) : lancer ESLint/Prettier/vue-tsc dans
  le container, pas sur l'hôte.
